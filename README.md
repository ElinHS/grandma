# 阿嬤家之味 · 品牌資料庫

台灣溫體黑豬 · 手工現做 · 冷凍厚切排骨專賣。
沒有嫩肉精、防腐劑、化學添加——像娘家媽媽的體貼。

## 內容

| 資料夾 | 內容 |
|--------|------|
| [`_brand/`](_brand/) | 品牌核心資料：產品、語氣、客戶、視覺、戰情記錄 |
| [`marketing/`](marketing/) | 行銷產出：團購文、社群圖卡 |

### `_brand/`（品牌核心）
- **product-info.md** — 產品資訊（三款鹹度：原味／幼幼／特製、規格、賣點、創辦故事）
- **voice-profile.md** — 品牌語氣（含定稿範例：產品文案＋品牌故事）
- **icp.md** — 理想客戶（主力：為孩子把關的忙碌媽媽）
- **brand-guide.md** — 視覺規範（色票、字體、包裝標示重點）
- **marketing-log.md** — 行銷戰情記錄
- **user-profile.md** — 稱呼設定

### `marketing/`（行銷產出）
- **團購文-媽媽群組.md** — 可直接貼群組的團購文
- **圖卡/** — IG 輪播圖卡 5 張（1080×1350 PNG＋HTML 原始檔）
- （落地頁已移到 repo 根的 **`docs/`**，供 GitHub Pages 發佈公開網址）
